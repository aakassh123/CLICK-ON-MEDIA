## ⚡ Interactive Modals Included

- **Get a Quote Modal**: Multi-service selector, budget slider, timeline picker, and project submission with confirmation feedback.
- **Consultation Scheduler**: Date, time, and topic selector for a 30-min growth strategy call.
- **Agency Showreel Modal**: Video preview showcasing agency milestones and client success.
- **Service Detail Modal**: Deep dive into deliverables, tools, and pricing for each service.
- **Project Case Study Modal**: Detailed breakdown of client challenges, solutions, and measurable ROI metrics.

## 🚀 Running the Project

### Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port shown in terminal).

### Production Build
```bash
npm run build
```
The optimized, production-ready static assets are output to the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
